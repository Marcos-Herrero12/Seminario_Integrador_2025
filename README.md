# Sistema de Gestión de Pasantías - UTN FRC

## Descripción general

Este proyecto consiste en el desarrollo de un sistema de gestión de pasantías centralizado para la UTN FRC. El objetivo principal es mejorar la vinculación entre estudiantes, universidad y empresas, facilitando la gestión y el seguimiento de oportunidades de pasantía de forma eficiente, segura y transparente.

## Objetivo del sistema de información

Diseñar e implementar un sistema de gestión de pasantías centralizado para la UTN FRC, que permita mejorar la vinculación entre estudiantes, universidad y empresas. El sistema debe ofrecer información actualizada, confiable y atractiva, además de agilizar los procesos de publicación, postulación y seguimiento de pasantías.

## Alcance

El sistema abarcará los siguientes procesos principales:

- **Publicación de oportunidades:** Empresas vinculadas a la facultad podrán publicar oportunidades de pasantías.
- **Validación y control:** El área administrativa de la universidad validará y controlará la información publicada.
- **Catálogo de pasantías:** Los estudiantes tendrán acceso a un catálogo actualizado de pasantías, con filtros para facilitar la búsqueda.
- **Comunicación interna:** Se gestionará un canal de comunicación entre la empresa y el estudiante dentro del sistema.
- **Reportes e informes:** La universidad podrá generar reportes sobre participación, inserción laboral y evolución de convenios.

## Tecnologías utilizadas

El sistema se desarrollará como una aplicación web modular y escalable, con los siguientes componentes tecnológicos principales:

### Back-end

- **Lenguaje:** Java
- **Framework:** Spring Boot  
  - Arquitectura orientada a servicios (SOA)
  - Control transaccional y manejo de excepciones
  - Validación multicapa y exposición de APIs RESTful

### Front-end

- **Framework principal:** React (SPA - Single Page Application)
  - Componentes reutilizables y enrutamiento dinámico
  - Consumo eficiente de servicios REST
- **Soporte estructural:** NestJS  
  - Lógica modular y escalable en el front, con soporte para estructuración de servicios

### Base de Datos

- **Motor:** MySQL  
  - Modelo relacional, diseño normalizado y control de integridad referencial
  - Priorización de trazabilidad y eficiencia en consultas

### Control de versiones

- **Sistema:** Git
- **Repositorio remoto:** GitHub  
  - Gestión de ramas por sprint, control de cambios y revisiones colaborativas

### Gestión de proyecto

- **Herramienta:** Jira  
  - Planificación de sprints, asignación de tareas y seguimiento de avance

### Diseño visual

- **Herramienta:** Figma  
  - Diseño de interfaces, prototipos interactivos y validación visual con stakeholders

Esta combinación tecnológica garantiza un desarrollo ágil, mantenible y alineado con buenas prácticas de ingeniería de software.
